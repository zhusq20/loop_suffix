# Loop投机解码：拒绝后复用旧后缀的零训练统计（2026-10-30）

用户2026-10-30授权。只运行公开权重的推理，不训练、不改模型；目的是在实现任何新调度器之前，量出三种免训练多词草稿来源的上限。讨论来源见本次对话；与[token canvas讨论稿§8](https://github.com/zhusq20/llm-memory-editability/blob/main/docs/reports/loop-token-canvas-proposal-20261030.md)的关系是：那里登记了“浅轮起草、深轮验证”已由LoopSpec／WaveFront完成，本批只测它们没有覆盖的复用环节。

## 1. 问题

WaveFront Decoding（WFD，arXiv 2609.23033，代码 `summerbro-hhj/wavefront-decoding@4345209`）在循环模型上用浅层读出起草下一个词，全深度核对；核对出错时，改正的词从深度0重新开始，后面在算的位置全部冲掉。冲掉的这些位置各自带着一个浅层猜测的词。

**主问题：这些被冲掉的词，有多少在改正之后仍然是正确的续写？** 如果多数仍然正确，纠错时可以把它们和改正的词同时重新开工（只保留词、状态从头算，仍然无损），省掉纠错后的逐个重开。

**次问题：** 不训练时，上文查找（prompt lookup）和回收池（loop自己产生的所有浅层候选）能提供多少“下一个词之后”的正确草稿。

## 2. 已有工作与本批的改变

| 工作 | 拒绝后怎么处理 | 本批 |
| --- | --- | --- |
| WFD | 冲掉改正位置之后的所有在算位置，从改正的词重开 | 在它的调度器上记录被冲掉的词，统计其与最终输出的一致性 |
| LoopSpec（2609.17184） | 剪掉后代分支，从已核对的词新开分支 | 不跑；只作归属 |
| LoopAhead（2610.21594） | 中间深度发现冲突时挂起分支，保留其状态以便恢复 | 挂起针对同一前缀；本批统计的是改正后前缀下复用旧词 |
| Geiping等（2510.14961） | 换输入时保留状态（近似、无核对） | 本批只保留词、不保留状态 |

## 4. 记录

在WFD的 `generate_wavefront_dynamic` 上做只加日志的拷贝，提交与回滚逻辑逐行不变：

- 每次起草：tick、位置、来源词、草稿词、浅层前8候选。
- 每次拒绝：tick、位置q、被拒草稿、改正的词，以及回滚前所有位置>q的在算词（位置、词、已走深度）。
- 每题：最终提交序列、R/P/C调用数、接受/拒绝计数。

## 5. 预定指标

记最终提交序列为y（WFD无损，即贪心AR输出），一次拒绝事件e发生在位置q，旧后缀为 `s_1..s_m`（位置q+1..q+m）。

**M1 后缀存活（主指标）。** 每个偏移k的一致率 `P(s_k = y_{q+k})`，以及最长一致前缀长度 `L_e`（从k=1起连续一致的个数）。按模型、类别与偏移报告；m的分布同时报告。

**M2 隐含的R调用节省（主指标）。** 采用可实现的“交叉核对”规则：纠错时把旧后缀与改正的词同时开工；当前一位置走到深度d、给出自己的草稿时，若与复用词不同就替换为草稿（等同WFD原行为）。在此规则下每个位置处理的词与WFD完全相同、提交序列不变，只是开工更早。设 `K_e` 为旧后缀中从k=1起连续等于WFD事后在同一位置所起草稿的个数，`g_e` 为到下一次拒绝位置的距离，则

  节省tick数 = Σ_e d · min(K_e, g_e − 1)，隐含R调用比 = 1 − 节省/WFD总R调用数。

这是忽略多出行计算成本的上限（单请求、带宽受限时多出的行接近免费）。另报告复用词错而被替换的行数，作为额外计算量。

**M3 上文查找。** 对y的每个位置p，用以p结尾的最后n个词（n=3→1回退）在prompt与已生成文本中找最近一次出现，取其后至多W−1个词作草稿；报告给出草稿的比例与一致前缀长度。

**M4 回收池。** 用位置≤p的所有起草事件的前8候选与已提交二元组，建“词→最近候选”表；报告top-1链与top-8树（逐步命中即可）的一致前缀长度。

M3、M4只报告命中统计，不折算加速。所有指标保留全量；空后缀（m=0）和生成末尾截断的偏移单独计数。

## 6. 校验（从简）

开跑前在每类前两题（共12题）上：原版 `generate_wavefront_dynamic` 与加日志拷贝的提交序列和全部计数逐项相同；同时跑WFD自带AR基线，报告逐token一致率（bf16下允许小于1，按WFD论文说明）。不做源码冻结与哈希。

## 7. 判读

- M2给出的隐含R调用节省在两个模型上都低于5%：不实现方案A。
- 节省主要来自某些类别（如翻译、摘要）：只在这些场景考虑实现。
- 后缀k=1一致而k≥2迅速下降：复用的价值只在填补一个位置，按此缩小实现范围。

本批不比较墙钟速度，不声称任何加速；所有结论只到“上限”层级。
